# Python Intermediate Projects (Set 2)

A collection of intermediate Python practice projects.

## Projects Included

### 1. ASCII Art Generator (`ASCII_art_generator/app.py`)

Converts any image into ASCII art using Pillow.

- Loads and resizes an image while preserving aspect ratio
- Converts it to grayscale
- Maps each pixel to an ASCII character
- Saves the result to a text file

```bash
pip install pillow
python ASCII_art_generator/app.py
```

### 2. Mini Chatbot (`Mini_chatbot.py`)

A simple rule-based command-line chatbot that answers basic greetings and questions.

```bash
python Mini_chatbot.py
```

Type `exit` to end the conversation.

## Requirements

- Python 3.x
- `pillow` (for the ASCII art generator only)
